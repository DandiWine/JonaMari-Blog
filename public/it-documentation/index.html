Cisco Commands and basic IOS navigation

CISCO Command line:
#


Command Description
enable Enter privileged EXEC mode
configure terminal Enter global configuration mode
hostname <name> Set device hostname
enable secret <password> Set privileged mode password
line console 0 Enter console line configuration
password <password> Set console password
login Enable login for console/VTY lines
service password-encryption Encrypt passwords in config
banner motd #<message># Set message of the day
Command Description
interface <type><number> Enter interface mode (e.g., GigabitEthernet0/1)
ip address <ip> <mask> Assign IP address
no shutdown Enable the interface
shutdown Disable the interface
description <text> Add description to interface
speed <value> / duplex <mode> Set speed or duplex
Command Description
ip route <destination> <mask> <next-hop> Static route
router ospf <process-id> Start OSPF process
network <network> <wildcard> area <area> OSPF network
router rip Enable RIP routing
version 2 Set RIP version
network <network> Specify network for routing protocol
Command Description
access-list <num> permit/deny <src> <wildcard> Create ACL
ip access-group <num> in/out Apply ACL to interface
Command Description
show running-config View current config
show startup-config View config in NVRAM
show ip interface brief Quick view of interfaces
show version IOS and hardware info
ping <address> Test connectivity
traceroute <address> Trace route to host
debug <option> Enable debugging
undebug all / no debug all Disable debugging
